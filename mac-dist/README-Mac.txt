Knit for macOS ─ 導入手順
================================

Knit(つなぐ)は、この Mac のキーボード/トラックパッドで Windows PC を操作できるように
するツールです。カーソルを画面の端へ動かすだけで Mac ⇄ Windows が切り替わり、
クリップボード(テキスト/画像/ファイル)と Windows の音声も共有されます。

旧 Tsunagu から乗り換える方
----------------------------
旧版の Tsunagu が動いたままだと、待受ポートの取り合いで Knit が起動に失敗します
(ログに [fatal] listen ... failed と出て終了します)。Knit.app を入れる前に:
1. メニューバーの Tsunagu アイコン →「終了」で止める
2. システム設定「一般」→「ログイン項目と拡張機能」で、Tsunagu が
   「ログイン時に開く」などに載っていたら削除する(ターミナルから
   launchctl unload ~/Library/LaunchAgents/local.tsunagu.plist を実行して
   同じフォルダの local.tsunagu.plist を削除すれば確実です)
3. 「アプリケーション」フォルダの Tsunagu.app をゴミ箱へ入れる
   (設定・履歴は残るので、あとで旧版へ戻せます)

設定とクリップボード履歴は Knit の初回起動時に自動で引き継がれます
(旧データも残ります)。やり直しになるのは「端末の登録」と
アクセシビリティの許可だけです。
もう1台の Windows も必ず Knit へ更新してください。片側だけだと接続できません
(Windows 用は GitHub Releases の Knit-win-<版>.zip から入手できます)。

インストール
------------
1. Knit.app を「アプリケーション」フォルダなどへドラッグして置く
2. 初回のみ: ダブルクリックで開けない場合は、Knit.app を右クリック
   (または Control+クリック)して「開く」→「開く」を選ぶ
   (開発者署名のないアプリの標準手順です。1回だけで、以降は普通に開けます)
3. 初回は登録の画面が出たあとにアクセシビリティ権限の確認が出ます。
   「システム設定を開く」→ システム設定の「プライバシーとセキュリティ」→
   「アクセシビリティ」で Knit をオンにすると、自動で次へ進みます
   (画面録画・入力監視の権限は不要です)。
   ここで「あとで」を選んで終了した場合も、もう一度 Knit.app を開けば
   ここから再開できます(登録と設定は保存されています)
4. メニューバーに Knit のアイコンが出れば起動完了です
   (未接続の間は「未接続」と併記されます)

はじめての接続
------------------
1. Mac のメニューバーの Knit アイコン →「設定…」(⌘,)→「接続」の
   「端末を登録…」を開く(初回起動では自動でこの画面が出ます)
2. Windows 側で Knit を起動すると、同じネットワークのこの Mac を自動で見つけます
   (Mac が1台なら自動で確認が始まります)
3. Mac の画面に4桁の確認番号と相手の名前・アドレスが出るので、
   Windows の4つの候補から同じ番号を選ぶ
4. Mac 側で内容を確かめて「許可」を押すと登録完了。以降は自動で接続します

自動で見つからないときは、Mac の画面に表示される6桁の手入力コードを
Windows 側に入力する方法もあります(Mac の IP アドレスを指定することもできます)。
コードは5分間有効です。長い暗号化キーはアプリが内部で交換・保存します。
手動で渡す必要はありません。

使い方(概要)
--------------
- カーソルを画面の右端へ(既定は 2 回)→ Windows へ切替
- Windows のカーソルを画面左端へ → Mac へ戻る
- Mac でコピーしたテキスト/画像/ファイルは、切替後に Windows で Ctrl+V で貼り付け可
- 詳細はメニューバーの各項目と設定画面から

ログイン時に自動起動させたい場合
--------------------------------
「システム設定」→「一般」→「ログイン項目」へ Knit.app を追加するのが
最も簡単です(追加後はログイン時に自動起動します)。

うまくいかないときは
--------------------
- 入れ替えの前には、起動中の Knit(旧 Tsunagu)を一度終了させてください
- Knit への乗り換えがうまくいかないときは、ゴミ箱から Tsunagu.app を
  「戻す」してもう一度開けば、旧版(Tsunagu)へ戻って使えます
  (旧版の設定・履歴は ~/.config/tsunagu に残っています。ゴミ箱を空にして
  しまった場合は、旧版の zip をもう一度展開してください)

アンインストール
----------------
自動起動を登録した場合は先に:
  launchctl unload ~/Library/LaunchAgents/local.knit.plist
  rm ~/Library/LaunchAgents/local.knit.plist
その後、Knit.app をゴミ箱へ入れてください。
設定・履歴(~/.config/knit)が残る場合は手動で削除してください。
