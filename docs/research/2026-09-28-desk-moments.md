# 机の一日から考える新機能

> **2026-09-28 追記:** ここの案は [本質を疑う](2026-09-28-essence-review.md) で取捨を判定した。採否はそちらに従う。

作成: 2026-09-28。机に Mac・Windows・Android タブレットを並べて働く一日を追い、
「手が止まる瞬間」「どっちだっけと考える瞬間」から機能を考えたもの。
前提とする原則: 各機器は自分の OS のまま使う / OS の標準機能でできることは作らない /
通知は集めずに重複を消す([製品判断の原則](../product-definition.md))。
実現性は OS の仕組みからの見立てで、試作による確認はしていない。

---

## 朝: 席に着く

**瞬間**: Mac を開いた。Windows は眠ったまま。Windows のキーボードを探して押す。

- **机ごと起こす**: Mac が目覚めたら、Windows(Wake-on-LAN)とタブレット(画面点灯)も起こす。
  Mac の最初の一押しで、机全体が仕事を始める
  - 見立て: Windows は Wake-on-LAN(BIOS と NIC の設定が要る場合あり)、タブレットはつながって
    いれば画面を点けられる。Mac を閉じた時の「机ごと眠る」も対になる

## 仕事中: 画面が 3 つ以上ある

**瞬間**: マウスを動かしたが、カーソルがどこにも見えない。3 台の画面を目で探す。

- **カーソルはここ**: マウスを小刻みに振ると、カーソルがある機器の画面に大きな輪が出る。
  macOS の「振って見つける」を、机の全機器に広げる
  - 見立て: どの機器にカーソルがあるかは Knit が知っている。表示は各機器の重ね描き

**瞬間**: 打ち始めたら、隣の機器に入っていた。パスワードを別の画面に打ちかけてひやりとする。

- **入力先のしるし**: 別の機器へ移って最初にキーを押した時だけ、その画面の端に小さく「Windows」と
  一瞬出す。慣れた人には邪魔にならない強さで
  - 見立て: 移った直後の最初の入力は Knit が判定できる

**瞬間**: 日本語を変換している途中で、カーソルが隣へ移った。変換中の文字が宙に浮く。

- **変換中の文字を置き去りにしない**: 変換の途中で境界を越えたら、その場で確定してから移る
  (または変換中は越えない)。海外製が扱わない、日本語で働く人だけが分かる不便
  - 見立て: 変換中かどうかは Mac 側で分かる(Knit は既に入力状態を追っている)

**瞬間**: タブレットのカーソルのまま、Mac の癖で ⌘⇧4 を押した。何も起きない。

- **スクリーンショットは、いる場所で(Android へ広げる)**: Windows では ⌘⇧4 / ⌘⇧3 が既に
  Win+Shift+S へ訳されている(crates/mac/src/main.rs の mac_shortcut_translation)。
  同じ翻訳を Android にも入れ、画面の撮影へつなぐ。撮った画像はクリップボード共有で Mac にも届く
  - 見立て: Android の中継(または将来のアプリ)で ⌘⇧4 を受けたら撮影の操作を送る

**瞬間**: Windows でダウンロードしたファイルを、Mac で使いたかった。

- **最近のダウンロードを、どこからでも**: メニューに全機器の最近のダウンロードが並び、
  選ぶと今いる機器へ届く
  - 見立て: 各機器のダウンロードフォルダの監視と、既存のファイル転送の組み合わせ

**瞬間**: ログインに 2 段階認証。コードがタブレット(スマホ)に届いた。見て、PC に打ち写す。

- **認証コードを、いまの画面へ**: 届いた確認コードを見つけたら、いまキーボードがある機器の
  入力欄へ貼れるようにする(ワンタップの確認つき・既定はオフ)
  - 見立て: Android は通知を読む許可で取れる。秘密を扱うため、明示の有効化・画面への表示の
    最小化・履歴に残さないことが必須

## 会議

**瞬間**: Windows で会議、Mac でメモ。発言しようとして、会議の窓を探してミュートを外す。

- **どこからでもミュート**: 決めたキーを押すと、会議をしている機器のマイクを切り替える。
  カーソルがどの機器にあっても効く
  - 見立て: 会議アプリのショートカット(Teams・Zoom 等)をその機器へ送る。対応アプリの表が要る

**瞬間**: 音楽はタブレット、会議は Windows。再生キーを押したら、関係ない機器が反応した。

- **再生キーは、鳴っている機器へ**: 再生・一時停止・音量キーは、カーソルの場所ではなく、
  いま音を出している機器へ届ける
  - 見立て: 音を Mac に集める機能([指示文](../plans/2026-09-28-audio-mix-prompt.md))ができれば、
    どの機器が鳴っているかを Knit が知れる

**瞬間**: 音を Mac に集めたら、タブレットの動画だけ大きすぎる。

- **机の音量ミキサー**: メニューに機器ごとの音量とミュート。1 台だけ下げられる
  - 見立て: 音を混ぜる処理の中で機器ごとに倍率をかけるだけ

## 離席と来客

**瞬間**: 子どもが Windows で宿題をする。こちらは Mac で仕事。カーソルが時々向こうへ行ってしまう。

- **貸し出し中**: 1 台をワンクリックで「貸し出し中」にすると、その機器へは越えない。
  返してもらえば元に戻る
  - 見立て: 接続先を一時的に外すだけ。複数台接続の仕組みの延長

**瞬間**: 席を立つ。(既出の「席を立てば机ごと鍵」)

## 夕方: 片付け

**瞬間**: 今日コピーしたものの中に、パスワードや個人情報が残っている気がする。

- **今日の履歴を消す**: クリップボード履歴を、全機器から一度に消す。一定時間で自動的に消す設定も
  - 見立て: Knit の履歴は Knit が持っているので作りやすい

**瞬間**: 帰る前に、Windows とタブレットを 1 台ずつ眠らせる。

- **机ごと眠る**: Mac を閉じたら、ほかの機器も眠る(朝の「机ごと起こす」と対)

## いつでも

**瞬間**: タブレットの電池が切れていた。

- **机の電池**: Mac のメニューに、タブレットやノート PC の電池の残りを並べる。少なくなったら一度だけ知らせる
  - 見立て: Android は電池の状態を読める。表示は既存の接続先メニューへ

**瞬間**: 3 台のサーバーに同じコマンドを打つ(開発者)。

- **同時に打つ**: 選んだ複数の機器へ、同じ入力を同時に送る。開発者・管理者に強く効く
  - 見立て: 入力を 1 台ではなく複数へ送る。誤爆を防ぐ明確な表示が要る

## 次に確かめること

1. 聞き取りで、上の「瞬間」が本当に起きているかを確かめる(起きていない瞬間の機能は作らない)
2. 頻度が高く他社にない「変換中の文字を置き去りにしない」を先に試作する
3. 認証コードとミュートは、安全面と対応アプリの調査を先に行う
