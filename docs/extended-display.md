# 実験的な拡張ディスプレイ（第2段）

macOS 12.3 以降で、`KNIT_EXTEND=1` を指定すると Mac に仮想ディスプレイを作成し、制御ポート +5（既定 TCP 24905）で動画接続を待ち受けます。制御接続中の相手と同じ端末鍵を Noise で認証します。画面収録の許可は「システム設定 › プライバシーとセキュリティ › 画面収録」で Knit に与えてください。仮想ディスプレイには非公開 API を使うため、macOS の環境によっては作成できません。

既定は 1920×1080、60 fps、H.264 12 Mbps です。Windows 側では動画を Media Foundation で復号して表示します。TCP 接続の Noise ラベルは `knit-video`、フレーム形式は `[種類 u8][タイムスタンプ u64 LE（µs）][長さ u32 LE][本体]` です。最初の種類 1 は設定 JSON、種類 2 はキーフレーム、種類 3 は差分フレームです。

## Windows に表示する

Mac と Windows の両方で `KNIT_EXTEND=1` を設定して Knit を起動し、通常の制御接続を確立します。Windows は同じ相手の制御ポート +5 に接続するため、この TCP ポートへの通信を許可してください。Windows の表示先は既定でプライマリ以外の最初のモニターです。1 枚の場合はプライマリを使います。

`KNIT_EXTEND_MONITOR` に 0 始まりのモニター番号を指定すると表示先を選べます。番号は Windows が列挙する順序です。範囲外の番号ではウィンドウを作成しません。映像は縦横比を維持し、余白は黒で表示されます。

表示中に Esc を 1 秒長押しするとウィンドウを隠せます。受信は継続し、タスクトレイの「拡張ディスプレイを表示」で再表示できます。制御接続が切れると動画接続も閉じ、ウィンドウを隠します。Mac のウィンドウを仮想ディスプレイへ移動すると Windows に映ります。操作は Mac 側のキーボードとトラックパッドを使用してください。

## Mac 単体での確認

画面収録を許可した環境で実行します。終了時に仮想ディスプレイを破棄します。

```sh
cargo run --locked -p knit-mac --bin extend_probe -- extend.h264
```

5 秒間取り込み、Annex B 形式で保存します。`ffprobe` がインストールされていれば解像度と読み取れたフレーム数を表示します。幅・高さ・fps・ビットレートを変更する場合は出力先の後に順に指定します。

```sh
cargo run --locked -p knit-mac --bin extend_probe -- extend.h264 1920 1080 60 12000000
```
