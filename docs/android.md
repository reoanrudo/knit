# Android タブレットをつなぐ

Mac のキーボードとトラックパッドで Android タブレットを操作する。Windows と同じく、
画面の端を越えるとタブレット側へ移る。
製品定義の「タブレットを参加させる方向」のうち **4. PC のマウス・キーボードでタブレット上の
アプリを操作する** にあたる。1〜3(タブレットから PC を操作・ファイルの受け渡し・画面の表示)は
対象外。

## 仕組み

- タブレットには専用アプリを入れない。Mac から adb で scrcpy のサーバー部品を送り込み、
  タブレット側に**仮想のキーボードとマウス**を作って入力を流す(ポインタはタブレットの画面に
  表示される。画面のミラーリングはしない)
- 中継は Knit の Mac 側に組み込まれていて、127.0.0.1 から本線へ「接続先の 1 台」として入る。
  暗号化と認証は Windows と同じ手順を通る
- **有線(USB)とワイヤレスのどちらでもよい**。見つけたタブレットを黙って操作対象にはせず、
  メニューで端末ごとに「操作する」を選んだものだけへ繋ぐ(選び直せば取り消せる)
- 同期するのは入力・テキストのクリップボード(双方向)・音量操作・音声の取得
  (タブレットで鳴っている音を Mac から出す。端末側でも鳴り続ける)

## 準備(Mac)

```bash
brew install android-platform-tools scrcpy
```

Knit はサーバー部品を `/opt/homebrew/share/scrcpy/scrcpy-server` から使う。scrcpy 本体が
起動できない状態(依存ライブラリの欠落など)でも、サーバー部品があれば動く。

## 準備(タブレット、初回のみ)

1. 設定 > デバイス情報 > ビルド番号(Xiaomi は「OS バージョン」)を 7 回たたいて、
   開発者向けオプションを有効にする
2. 開発者向けオプションで **USB デバッグ** をオンにする(Xiaomi は「USB デバッグ(セキュリティ
   設定)」もオンにしないと入力を受け付けない場合がある。未確認)
3. USB ケーブルで Mac とつなぎ、タブレットに出る「USB デバッグを許可しますか?」で許可する
   (「このパソコンからの接続を常に許可」にチェックすると次回から聞かれない)
4. 物理キーボードの配列を日本語にする(設定 > 追加設定 > 言語と入力 > 物理キーボード)。
   英語配列のままだと記号の位置が Mac の JIS 配列とずれる
5. (推奨)マウスの「ポインタの加速」があればオフにする。Knit はタブレットのポインタ位置を
   推定して画面端での戻りを判定するため、加速が強いと推定と実物がずれる

ワイヤレスで使う場合は、開発者向けオプションの **ワイヤレスデバッグ** をオンにし、
「ペア設定コードによるデバイスのペア設定」で一度だけ `adb pair IP:ポート コード` を実行する。
以後は Knit が見つけて自動で繋ぐ。

## 使い方

この方式(adb 中継)は**開発者向けの精密モード**で、メニューバーには項目を出さない。
通常はタブレットの Knit アプリ([Androidアプリの説明](../android/README.md))を使う。
adb で操作するには、Mac の Knit を `KNIT_ANDROID_ADB=1` で起動する(`~/.config/knit/env` に書く)。
USB でつなぐか、ワイヤレスデバッグをオンにすると、Knit が見つけて自動で繋ぐ。
タブレット側で「USB デバッグを許可」を選ぶ必要がある。見つけた時と、接続できない時は通知で知らせる。

端末ごとの許可・拒否を細かく決めたい場合は、`~/Library/Application Support/Knit/android-tablets.txt`
(1 行 1 端末: `allow` または `deny`、端末キー、表示名をタブで区切る)を直接編集する。
この設定は環境変数より優先される。

- **Mac→タブレット**: Windows と同じ画面端から越える(Windows と同時に接続中は、設定の「接続」で操作する端末を切り替える)
- **タブレット→Mac**: 反対側の端へ押し当てる、または F13。ケーブルを抜いた時も Mac に戻る
- **キー**: ⌘→Ctrl、⌥→Alt、control→Meta(Windows と同じ対応)。⌘C/⌘V/⌘A/⌘Z がそのまま効く。
  かな・英数キーで日本語入力を切り替えられる。画面を移る時は Mac のかな/英数の状態を引き継ぐ
- **クリップボード**: Mac でコピー → タブレットへ移って貼り付け、およびその逆
- **画面の回転**: 向きが変わると数秒で接続し直し、新しい画面サイズで続ける
- **複数台**: 複数のタブレットをつないだ場合は、それぞれが接続先の 1 台になる

## 設定(`~/.config/knit/env`)

設定ウィンドウの「ジェスチャー」で、ナビゲーションとピンチ拡大・縮小を切り替えられる。
オンにすると、タブレット操作中のMacのピンチを2本指タッチとして送る。
2本指の縦・横スクロールは既存のスクロール経路を使う。
ナビゲーションをオンにした場合は、Macのトラックパッドで次の操作を利用する。

| 指の操作 | タブレットの操作 |
|---|---|
| 2本指で左端・右端から内側へスワイプ | 戻る |
| 3本指で左・右へスワイプ | アプリ切替 |
| 3本指で上へスワイプして離す | ホーム |
| 3本指で上へスワイプし約0.4秒停止 | 最近のタスク |
| 3本指で下へスワイプ | スクリーンショット |

通常の横スクロールで「戻る」は発火しない。Mac操作中・Windows操作中は無効。
Mac側でも3本指操作が反応する場合は、macOSの対応するジェスチャーを4本指へ変更する。
指の位置を取得できない環境ではナビゲーションのスイッチを無効にする。
この位置取得はmacOSの非公開APIを利用する試験実装であり、OS更新・スリープ復帰・
外付けトラックパッドの再接続を含む互換検証と、実指による端末操作の確認は残っている。

配置図は液晶の物理寸法を基に描く。高い解像度でも巨大な液晶として扱わない。
物理DPIが取得できない端末はMacより小さい概算表示となる。詳しい検証範囲は
[タブレット・トラックパッド改善記録](reviews/2026-09-30-tablet-trackpad.md)を参照。

| キー | 既定 | 内容 |
|---|---|---|
| `KNIT_ANDROID` | 有効 | `0` で Android 接続を無効にする |
| `KNIT_ANDROID_GAIN` | 160 ÷ 画面密度 | ポインタ移動の倍率。タブレット上で動きが速すぎる時は小さく、遅い時は大きくする |
| `KNIT_ADB` | 自動検出 | adb の場所 |
| `KNIT_SCRCPY_SERVER` | 自動検出 | scrcpy サーバー部品の場所 |
| `KNIT_SCRCPY_VERSION` | 自動検出 | サーバー部品の版(版が合わないとサーバーが起動しない) |

## 検証状況

| 項目 | Xiaomi Pad 6S Pro 12.4(HyperOS 3 / Android 16、USB) | Android 16 エミュレーター |
|---|---|---|
| 発見・選択待ち・操作する・取消(接続がその場で切れる)・選択の保存 | 確認済み(e2e_consent) | — |
| 仮想キーボード・マウスの登録、マウス移動が入力層へ届く | 確認済み | 確認済み(e2e_device) |
| キー入力が入力層へ届く、ping/pong | 未実施(実機の入力欄・クリップボードを変えるため) | 確認済み |
| ポインタ移動量の補正 | 補正値 0.400 を自動算出。実測は不可(HyperOS が位置を出さない) | 補正後 0.78〜1.02 倍 |
| 画面上のポインタの見え方・端での戻り・JIS 記号・かな/英数 | 未確認(目視が必要) | — |

## 既知の制約

- ポインタは相対移動で送るため、Android 側の加速で推定位置とずれることがある。画面の端では
  両方が端で止まるため、端へ押し当てると揃う
- 画像・ファイルのクリップボード共有は未対応(タブレットのクリップボードへ入れる公開手段が
  Android にないため。ファイルは設定画面の「タブレットのDownloadへ送る…」から明示的にのみ送れる)。
  タブレットからの Mac 操作と画面表示も対象外
- タブレットでコピーした内容は、Mac のクリップボード履歴では ADB 中継では「Windows」、
  専用アプリでは「タブレット」と表示される

## 専用アプリに関する補足

以下は[Androidアプリ](../android/README.md)を使っている場合の動作です(ADB 中継には当てはまりません)。

- **共有で送れるもの**: Android の「共有」から Knit を選ぶと、画像(スクリーンショット含む)・
  動画・音声メモ・テキスト・ファイルを送れる。複数選択にも対応する
  (1 ファイル 256MiB 上限。動画は長い映像で上限を超えやすい)
- **共有が届く仕組み**: 共有は Mac がそのタブレットを選択している間に届く。未接続・未選択で
  共有した場合は最新 1 回分だけアプリが保持し、Mac とのファイル経路が通った時点で自動送信される
  (Mac の画面の端へカーソルを移動すると、そのタブレットが選択される)
- **再起動後の動作**: 端末の再起動後・アプリ更新後は、登録済みで停止操作していなければ
  自動で待機を始める(Mac が見つからなくても再接続を試み続けるが、通知の張り替えは行わない)。
  止めるには通知の「接続を停止」。停止したまま再起動しても自動開始しない
- **更新と署名**: 配布 APK は開発用署名(ビルド環境ごとに異なる)。更新で「署名者が現在と
  異なるため中止」と出たら、アンインストール→再導入が必要(この場合 Mac との再登録もやり直し)

## 確認方法

```bash
# 端末をつないだ状態で(シリアルは adb devices で確認)
KNIT_E2E_SERIAL=<シリアル> cargo test -p knit-mac e2e_consent -- --ignored --nocapture
KNIT_E2E_SERIAL=emulator-5554 cargo test -p knit-mac e2e_device -- --ignored --nocapture
KNIT_E2E_SERIAL=emulator-5554 cargo test -p knit-mac e2e_pointer_gain -- --ignored --nocapture
```

e2e_device はキー入力とクリップボードの書き換えを行うため、普段使いの実機では実行しない。
