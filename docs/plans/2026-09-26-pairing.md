# 初回登録を6桁コードにする

目的：個人のMacとWindowsを、長い鍵や設定ファイルを扱わずに登録する。

操作はMacで「Windowsを登録」を開く→Windowsで近くのMacを選ぶ→Macに表示された6桁を入力する。発見できなければIPを指定できる。IPは探索先であり認証情報ではない。

SPAKE2 (RustCrypto spake2 0.4)で短いコードからセッション鍵を導出し、その鍵で既存のNoiseハンドシェイクを相互認証する。認証後の暗号化経路でMacの永続キーを渡す。コード自体や永続キーを探索パケットへ含めない。新しい暗号方式を自作しない。

招待は明示的に開いた画面だけで有効。5分・最大3接続試行・成功1回で終了する。閉じたら待受と進行中接続を停止する。Windowsの保存成功を確認して完了を表示する。保存済みキーは上書きしない。既存env設定は優先する。

探索用UDPと登録用TCPは24904。招待中だけ待ち受ける。自動発見はLAN、隔離ネットワーク/Tailscaleでは手動IPを使う。探索は非認証なので最終的な信頼判断は6桁コードの認証による。端末名は表示用に制限する。

実装順：共通プロトコルと失敗試験→Mac招待画面→Windows探索・入力画面→保存済み接続先の再利用→両OSビルド・実機画面確認・配布物更新。

検証：正しいコード、違うコード、改ざん/異常長、保存失敗、期限、試行上限、キャンセル、招待再利用拒否。通常の登録試験は一時保存先を使い、稼働アプリや資格情報を変更しない。

参照：https://docs.rs/spake2/0.4.0/spake2/ 、https://magic-wormhole.readthedocs.io/en/latest/client-protocol.html
