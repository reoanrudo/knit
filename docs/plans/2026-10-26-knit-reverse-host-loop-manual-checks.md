# 逆方向(Win=サーバ)強化ループ — 実機確認リスト(人間向け引継ぎ)

対象: 逆方向構成(Windows=ホスト/Mac=クライアント)。ループは自動検証できない
実機挙動をここに残す(design: docs/plans/2026-10-26-knit-reverse-host-loop.md §最終検収 5)。
実施したら行頭に [x] を付けてコミットしてください。

## 準備
- [ ] 両側を今回のブランチ(loop-reverse-host)のビルドで起動
- [ ] 同一 LAN(Tailscale 経由の確認は最後の項目で)

## 切替と接続
- [ ] どちらか 1 台の設定で役割を逆方向へ切替 → 「切り替えを相手へ送りました…」→
      両側で自動再起動 → 接続が戻る(usage.md「接続の方向」)
- [ ] 環境変数 KNIT_ROLE 固定中は GUI 切替が無効になり案内が出る
- [ ] 同一 LAN で IP 指定なし(自動発見)で接続できる

## 本線・入力
- [ ] 境界切替(画面端)・入力共有・⌘Tab / cmd+Tab・スクロール方向
- [ ] RTT(遅延)表示が Mac メニューと Win ステータス窓の両方に出る

## クリップボード・ファイル(双方向)
- [ ] テキスト・画像のクリップボード双方向
- [ ] ファイル: Windows の Ctrl+C → 切替 → Mac で ⌘V(Downloads/Knit へ)
- [ ] ファイル: Mac の ⌘C → 切替 → Windows で Ctrl+V
- [ ] 掴み D&D の境界越え(両向き)・Esc 中止

## 音声(今回の変更の主対象)
- [ ] **KNIT_AUDIO_HOST を設定しないで** Windows の再生音が Mac で鳴る(受理相手への自動追従)
- [ ] KNIT_AUDIO_HOST に明示指定した場合はそちらへ向く(上書きの確認)
- [ ] 接続中の Win スピーカー自動ミュートと切断での復元

## 診断・表示(今回の変更)
- [ ] Mac(クライアント役)の診断: 切断中でも「Knitの常駐が止まっています」にならず、
      「待ち受け ✓」・音声の待受(24901)行が出る
- [ ] Windows(ホスト役)の診断: 切断中に「{Mac名} からの接続を待っています…」+
      受信許可(TCP 24900〜24902・UDP 24903)の案内が出る
- [ ] Windows トレイ: ホスト役で切断中「未接続・相手からの接続を待機中」
