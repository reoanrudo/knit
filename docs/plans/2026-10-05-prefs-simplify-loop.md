# 設定GUI シンプル化ループ(2026-10-05 実行済み)

## 目的

前日の懐疑20周ループで説明・案内・注記を積み上げた設定画面を、逆方向の圧力
(削る・統合する・畳む・短くする)で引き締める。基準は「初めて開いた人が30秒で
目的に届くか」。困った時だけ必要な情報は常設から退避(ツールチップ・ログ)してよい。

## 実行方法(ZCode)

1. 共通参照(/tmp/knit-prefs-simplify-ref.md)に**保護リスト**(前ループで入れた
   確認ダイアログ・エラーの居場所・復活機能等10項目)を書き、全エージェントに遵守させる
2. 各周を直列に: read-only-reviewer が観点1つで指摘最大5件 → builder が全件対処
   - 検証: cargo check/test --workspace --exclude knit-win・cargo build -p knit-mac
     ・--preview-ui スモーク・コミット禁止
   - 保護リストと衝突する提案は「短くしつつ要点保持」「別場所へ退避」の両立案で
3. 最終周は「削りすぎ検収」(保護リスト全項目照合・退避先実在確認・静的化の副作用検証)

## 10観点

| # | 観点 | 主な対処 |
|---|---|---|
| 1 | 初見の第一印象 | 直接つなぐ開閉化(未設定時1行)・その他節のボタン片側化・暗号化行67→31字 |
| 2 | 常時表示行・毎秒書き換え | 静的4行をbuild時1回へ・非表示ウィンドウの毎秒50メッセージ→0 |
| 3 | 文言の短縮 | 3文789px→381px 等5行・否定が切れる行の解消 |
| 4 | 重複の統合 | 登録導線3重→1・権限案内2行→1・「ログを開く」二重導線の解消 |
| 5 | ページ・カード構成 | 「その他」節をサイドバー下部へ・下段カードを登録専用化 |
| 6 | 詳細の畳み込み | 状況限定注記5行をツールチップ/条件表示へ・音量スライダ条件表示 |
| 7 | コントロール数 | トークン節を下段カードへ降格・未接続時エイリアス欄を隠す |
| 8 | メニュー削減 | 注記行→ツールチップ・日常操作を上へ並び替え・「利用できます」削除・履歴0件で項目ごと隠す |
| 9 | ウィザード軽量化 | 権限画面112→54/86→38字・2台目完了に3台目勧誘を出さない(6秒→3秒) |
| 10 | 削りすぎ検収 | メニュー状態行の manual 対応漏れ・案内の位置特定を修正(2件) |

## 2026-10-05 実行結果

- 検出43件・対処40件・見送り3件(理由付き: メニュー「端末を登録…」削除×2は前ループ
  導線の逆戻り、履歴チェック削除はWin側と非対称のため)
- テスト: 開始時437件 → 終了時443件(全緑)
- 定量: 接続ページの操作部品21→14(−33%)・常設行と毎秒書き換えの大幅削減
  (SECURE/ACCEPT/BIND/ENV_NOTE を build 時1回へ・非表示ウィンドウの書き換え0)
- 検収で保護リスト10項目を照合: 9項目は維持、状態行の整合(手動接続)のみ
  片側実装の不整合を検出し修正(前々ループの残存リスクがここで確定・解消)

## 運用の注意

- 「減らす」ループには保護リストが必須: 減らす圧力は前ループの改善を平気で壊す
  (本ループでも検収で不整合1件を検出)。削る前に守るべきものを文書化すること
- ツールチップ退避の定番パターンが3つできた: label の上書き型(setToolTip を別打ち)・
  check の caption 型・NSMenuItem 型(setToolTip 導線)
- 見送り判断はオーナーが行う: レビュアーは「削れる」を見つけるが、削ってよいかは
  導線全体・対称性(Win側)・前ループの意図との兼ね合いで決める
- 実機確認が残る: 直接つなぐ開閉のクリック挙動・サイドバー「その他」の視認・
  未接続時のエイリアス欄非表示・履歴0件のメニュー・ウィザード新文言
