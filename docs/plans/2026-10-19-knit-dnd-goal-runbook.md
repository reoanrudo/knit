# D&D ゴール計測手順(G1〜G7・N1) — 利用者が実機で行う

対象: [声から作るゴール](2026-10-19-knit-dnd-voice-goal.md)の達成条件を実機で測る。
所要: 40〜60分。前提: Mac と Windows を同じビルドへ更新(片側だけでは要件を満たせない)。
記録は各表に書き、終わったら表と写真ファイル名を貼る。**結果のない回は作らない**(打ち切ったら理由を書く)。

## 準備

1. 両側へ最新のビルドを入れる(Mac はこのリポジトリの `target/debug/knit-mac`、Windows は同じコミットのビルド)
2. 受信フォルダを開いておく(Mac: 設定「受信フォルダ」/ Windows: トレイ「受信フォルダを開く」)
3. 画面録画を開始する(タイミング計測と、無言終了の判定用)
4. W1(遅延提供)を試す回だけ、Windows 側で `KNIT_LAZY=1` を設定して起動する(既定は無効)

## G4 中断と再開

1. 500MB を転送し、30% で Wi-Fi を切る
2. 受信フォルダ/保存先に部分ファイルが**残っていない**ことを確認(隠しファイルも見る)
3. 再接続し、同じ操作をやり直す。**最初から送り直すか、続きから送るか**を記録
4. 再送量のログ(Windows: `[bulk]` / Mac: `[bulk]`・`[drag]`)を貼る

**合格**: 部分ファイル0。再試行は送信済み分を再利用(現状は最初から = 未達として記録でよい。N4 の根拠になる)。

## N1: I9 PoC(実機で判断する4点)

ランナップ §5.6 と同じ手順。結果を4行で返す。

1. 大きなファイル(1GB 以上)を Windows から掴み、Mac のデスクトップへ運ぶ
2. 離した瞬間からファイルが現れるまでの時間を測る(現状は全データ到着後)
3. その間、「受け取り中 N%」がカーソル近傍に出ているか
4. 途中で接続を切る → 部分ファイルが残らないか

**判断**: 「待たされるが進捗が見えるので不安ではない」→ I9 は優先度を下げる。「数分単位で我慢できない」→ I9 を実装する。
あわせて、Finder が進行表示を出して待つか(書き出し完了を待つか)を1回だけ見る。

- 写真はファイル名を付ける(例: g1-04-1gb.png)
- 失敗回はログ行(`[drag]` `[bulk]` `[notice]`)を添える
