# ドクター(自己診断・自動修復)の設計

## 目的
各アプリが自分の不具合を見つけ、安全な範囲を自動で直す。直した内容は記録に残し、
診断画面(「接続を診断…」)から確認できる。

## 方針(利用者の決定: 完全自動・対象はすべて)
自動修復の範囲は **Knit 自身の状態** に限る。次は自動では行わず、案内だけ出す。
- OS の権限の付与(アクセシビリティ・UAC)。付与できない/してはならない
- 管理者権限が要る操作補助の導入・更新(トレイの項目から利用者が一度承認する)
- 登録情報(接続キー)の作り直し・削除、利用者のデータの削除

## 構成
- `knit_common::doctor`: 修復の種類(Fix)、実測(Finding)、連発の抑止(Governor)、記録(Journal)
  - 同じ修復は最短間隔を空け、10 分の窓で回数に上限を置く(直す→壊れる→直すの無限ループを防ぐ)
  - `KNIT_DOCTOR=0` で修復だけ止められる(診断と記録は続く)
- 各アプリが実測して Finding を作り、`doctor::cycle` に修復の実行を渡す

## 現在の項目
| アプリ | 異常 | 修復 |
|---|---|---|
| Windows | Mac から押したボタンが 5 秒以上離されない | 押下中の入力を離す |
| Windows | Mac と 120 秒以上つながらない | 再接続の待機を飛ばす |
| Windows | 操作補助が導入済みなのに応答しない | 案内のみ(記録に残す) |
| Mac | Windows 操作中に接続が 3 秒以上途切れる | カーソルと入力を Mac に戻す |
| Mac | Mac に戻ったのにカーソル固定が 3 秒以上残る | 同上 |
| Mac | 隠れたカーソル・転送停止(既存の自己修復) | 既存のまま。動作を記録に残す |

## 未実装
- Android アプリ(アプリの改修とリリースが別途必要)
- 音声・クリップボード・ファイル転送の停止の検知と修復(停止の判定基準を実機で決める)
- 「境界・カーソル」の計測(ポインタ推定のずれ)
