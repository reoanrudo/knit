# 設定画面の方針(何を置き、何を置かないか)

決めた日: 2026-09-30。判断は [本質の整理](research/2026-09-28-essence-review.md) の 5 つの問いと、次の物差しによる。

**Knit の本質は「入力と持ち物が、何も考えずに境界を越えられること」。** 設定画面には次の 3 種類だけを置く。

1. 最初に 1 回だけ要るもの(端末の登録、画面の並び)
2. 毎日の体感を左右するもの(切替の方式とキー、スクロール、共有する内容)
3. 動いているかを確かめるもの(接続の状態)

調整値(時間・倍率など)は、既定値で境界を越えられるなら置かない。

## Mac の設定(4 ページ)

| ページ | 置くもの |
|---|---|
| 接続 | この Mac と相手の状態、操作する端末の選択 / 端末の登録 / 版とアップデートの確認 / 困った時(ログを開く・再起動) |
| 画面配置 | 画面の並び(ドラッグ)と、接続先の位置の選択 |
| 操作 | 切替方式・切替キー / スクロール方向と速度 / タブレットのナビゲーションとピンチ(**タブレットが見つかっている時だけ表示**) |
| 共有 | テキストと画像 / ファイルの受け渡し / 接続先の音声の再生 / 接続中の相手スピーカーのミュート / Macのコピーを履歴に残す |

## 置かないと決めたもの

| 項目 | 扱い | 理由 |
|---|---|---|
| 「接続先を操作する」「Macに戻る」ボタン | 削除 | 画面の端・ショートカット・メニューバーで足りる。設定の役割ではない |
| 端で待つ時間・2回触れる間隔 | 削除(既定値を使う) | 境界を越えられることが本質。調整させるほどの個人差はない。必要な人は環境変数 |
| ⌘キーを Alt に割り当てる | 削除 | 既定の Ctrl で足りる。環境変数 `KNIT_CMD_ALT` |
| カーソル速度・スクロール互換モード | 削除 | 通常は触らない。環境変数 |
| ファイル送信ボタン | 削除 | 設定ではなく操作。メニューバーにある |
| 音量ボタン(下げる・上げる・ミュート) | 削除 | 音量キーの転送で足りる |
| ジェスチャーのページと一覧 | 廃止 | タブレットが無い人には無関係。スイッチは「操作」へ条件付きで移し、一覧は [android.md](android.md) に任せる |

削除した項目の動作と保存済みの値は、環境変数と設定ファイルからは従来どおり使える
([usage.md の「うまく動かない時」](usage.md#うまく動かない時))。

## Windows の設定(未整理)

Windows の設定画面も同じ方針で整理する予定。今は「接続・画面配置・操作・共有」の 4 ページで、
「画面配置」と「操作」は Mac の設定の表示・説明が中心。Windows は受け手なので、
「接続」と「共有」の 2 ページに寄せるのが本来の形。実機で見た目を確認できるようになってから行う
(Win32 の画面は座標で組んでおり、実機なしでは崩れを確認できないため)。
