# 設定画面の方針(何を置き、何を置かないか)

決めた日: 2026-09-30。判断は [本質の整理](research/2026-09-28-essence-review.md) の 5 つの問いと、次の物差しによる。

**Knit の本質は「入力と持ち物が、何も考えずに境界を越えられること」。** 設定画面には次の 3 種類だけを置く。

1. 最初に 1 回だけ要るもの(端末の登録、画面の並び)
2. 毎日の体感を左右するもの(切替の方式とキー、スクロール、共有する内容)
3. 動いているかを確かめるもの(接続の状態)

調整値(時間・倍率など)は、既定値で境界を越えられるなら置かない。

## Mac の設定（4ページ・2026-10-16 実装）

承認デザインをAppKitへ実装した。内容サイズ1040×700pt、左ナビは **接続 / 画面配置 / 共有 / その他** の4項目。「切替」ページは置かず、既存の切替キー・環境変数の動作は保持する。

- **接続**: このMacと接続中端末（端末名＝PC名で表示。名前…ボタンでエイリアス編集）、遅延と直近RTTの推移、診断（結果はページ内に表示）、端末追加、再接続。手動接続の役割・アドレスは折りたたむ。
- **画面配置**: Macの画面グループ、独立したタブレット。各画面にMac・Windows・Android別のオリジナルホーム画面画像を埋め込む（実画面の取得や転送はしない）。背景は淡いグレー、左ナビは一段濃いグレーとし、ダークモードにも追従する。端末は種別語ではなく端末名（PC名）で示す。矢印を使わず対応する辺の帯と端点で示す。端末別の送出元・送出先範囲、感度0.2〜3.0（標準1.0）を編集する。数値入力も用意した。選択は編集対象だけを変え、操作先を切り替えない。
- **共有**: Windows音声の再生・音量・出力UID、Windowsスピーカー消音、コピー・ファイル・履歴（保存件数は10/50/100/200件）、受信フォルダ（受信後に開くかを選択可）、コピーを履歴に残す。出力機器の喪失は停止をラッチし、既定スピーカーへ代替しない。確認音には都度の同意が必要。
- **その他**: 言語、切替キー（4候補＋ほかのキーを登録、環境変数固定時は無効表示）、キー変換のプレビュー（現在の設定での⌘/Ctrl/Altの対応）、更新の自動確認、既存ログイン登録のRunAtLoad、接続・転送完了の通知、設定アーカイブ、ログ保存、再起動・初期化。

配置・範囲・感度・共有・一般項目は下書きで、共通の「元に戻す / 適用」を使う。未編集項目は外部変更に追従する。複数ファイルへの保存は検証後に順次実行し、後段が失敗したら先行分の復元を試みる。クラッシュを含めた単一トランザクションではなく、復元失敗もエラーとして表示する。

端末別設定は `screen-settings.json`、通知・受信先は `desktop-settings.json`。設定アーカイブv2は一般・共有・端末別範囲と感度を含む。接続方向、端末の位置、認証情報、OSのログイン登録は読み込みで変更しない。受信先の変更は再起動後に有効。

プレビューのページ番号は `--preview-page 0〜3`。`--preview-tablet`、`--preview-language ja|en`、`--preview-light`、`--preview-dark` を使える。通信・入力送信・保存・音声再生は行わない。旧 `--preview-narrow` と `--preview-check-language` は旧UI用のため、この4ページ版の検証手段ではない。

**検証・制限**: Mac実画面をプレビューで確認し、単体・統合テストとWindowsテストコードのクロスビルドを実施。実音、実端末間の自由範囲移動、VoiceOver全操作、狭幅対応は未検証。識別ボタンは配置図内の番号表示であり、実ディスプレイ全面へのOSDではない。Windowsの新しい送出先範囲を有効にするにはWindows側も更新する必要がある。Windowsの設定画面自体は今回の4ページ版へ変更していない。

実画面と検証記録は [実装記録](<../output/2026-10-16-knit-settings-refined/IMPLEMENTATION.md>)。

## 旧Mac設定の記録（5ページ・2026-10-07）

方向 → 接続状態と登録 → 接続先の順で「いまどちらへつなぐのか」を読み取れる構成。
日本語と英語を「その他 / General」で切り替える。部品を再生成せず文字列だけを変更し、
未保存のアドレス、フォーカス、保存エラーを保つ。言語はこの Mac の設定だけに保存し、
遠隔設定からは変更できない。端末名、アドレス、通信・保存キーは翻訳しない。

通常の内容サイズは 720×700pt。タブと保存結果は固定し、本文だけをスクロールする。
大見出し・細い区切り・余白を主体にし、枠の多重化や装飾を避ける。状態のまとまりだけを
淡いシステム色の NSBox で示し、ライト／ダークの appearance に追従させる。
接続先は「保存して再接続 / Save & Reconnect」による明示保存を維持し、他の設定の
自動保存と区別する。環境変数の優先、役割切替の確認、登録、配置のドラッグは維持する。
手動接続用の共通トークン欄は今回追加しない。設定ファイル経由の既存動作は維持する。

| ページ | 置くもの |
|---|---|
| 接続 / Connection | 接続の方向(ホスト/クライアントの 2 択) / 状態、必要時だけ表示する端末・Android・待受情報 / 端末の登録 / 接続先と明示保存・再接続 |
| 画面配置 / Displays | 画面の並び(ドラッグ)、クリックによる端末選択、現在の接続位置 |
| 切替 / Switching | 切替キー・滞在時間スライダ(「端で少し待つ」のとき) / 環境変数による固定の説明。切替方式そのもの(タップ回数・待ち・キーのみ)は環境変数と遠隔適用で指定する |
| 共有 / Sharing | テキストと画像 / ファイルの受け渡し / 相手の音声の再生と音量 / Mac のコピーを履歴に残す |
| その他 / General | 日本語／English の選択 / 再起動 / 登録・設定の初期化 |

プレビューは `--allow-multiple --preview-ui --preview-page 0〜4` で通常アプリと共存させる。
`--preview-language ja|en`、`--preview-light`、`--preview-dark`、`--preview-narrow` で表示条件を変えられる。
プレビューでは通信・保存・初期化を行わない。debug ビルドの `--preview-check-language` は、
実際の AppKit 部品で言語変更時の未保存入力・フォーカス・保存エラー保持を検証する。

## 置かないと決めたもの

以下は過去の整理方針。2026-10-07 の再設計では、新しい調整項目を増やさず、
現行コードに存在する調整の保存意味論と表示条件を優先して維持した。

| 項目 | 扱い | 理由 |
|---|---|---|
| 「接続先を操作する」「Macに戻る」ボタン | 削除 | 画面の端・ショートカット・メニューバーで足りる。設定の役割ではない |
| 端で待つ時間・2回触れる間隔 | 削除(既定値を使う) | 境界を越えられることが本質。調整させるほどの個人差はない。必要な人は環境変数 |
| ⌘キーを Alt に割り当てる | 削除 | 既定の Ctrl で足りる。環境変数 `KNIT_CMD_ALT` |
| カーソル速度・スクロール互換モード | 削除 | 通常は触らない。環境変数 |
| ファイル送信ボタン | 削除 | 設定ではなく操作。メニューバーにある |
| 音量ボタン(下げる・上げる・ミュート) | 削除 | 音量キーの転送で足りる |
| ジェスチャーのページと一覧 | 廃止 | タブレットが無い人には無関係。スイッチは「操作」へ条件付きで移し、一覧は [android.md](android.md) に任せる |

削除した項目の動作と保存済みの値は、環境変数と設定ファイルからは従来どおり使える
([usage.md の「うまく動かない時」](usage.md#うまく動かない時))。

## Windows の設定(2026-10-12: Mac と同じ 5 ページ構成へ統一)

Mac 側と同じ上部タブ・5 ページ(接続 / 画面配置 / 切替 / 共有 / その他)・同じ見出しと
文言で構成した。旧サイドナビ+4 ページ構成、接続ページのトークン欄・状態図・
キーボード表・スクロール等の遠隔調整は廃止した。

- **接続**: 役割の 2 択(Mac と同じ「— 相手の端末が接続しに来ます」形式)→ 状態カード
  (状態行は Mac と同じ形式。「このPCのアドレス」行で IP 指定時に渡す自分のアドレスを
  確認できる)→「接続先の端末」IP 入力と「保存して再接続」。**IP アドレスでの直接接続は
  この画面から完結する**(空欄なら自動発見・カンマ区切りで複数可。ホスト役割の間は入力を
  無効にするのは Deskflow と同じ対応)。手動接続用の共通トークン欄は Mac 側と同じく
  置かない(.env の KNIT_TOKEN 運用は維持し、状態行が「直接つなぐで待機中」と出す)
- **画面配置**: ドラッグでこのPC の四角を相手(名前入りのブロック)の周り 8 方位へ
  置く(Mac の配置キャンバスと同じ操作)。コンボと「既定(右)に戻す」は廃止
- **切替**: 切替キーと滞在時間スライダ(50-1000ms)の遠隔設定(接続中のみ)
- **共有**: 「渡すもの」(テキストと画像 / ファイルの受け渡しのチェック)、「音声」、
  履歴の説明、「相手側の設定」(Mac の共有ページと同じ項目のトグル)
- **その他**: 再起動・ログ・診断、「すべての登録を初期化…」(新設。Mac と対)と
  「すべての設定を初期化…」。初期化ボタンは赤で区別する(Mac の mark_destructive と同じ)

初回導線(はじめての接続)は Mac の招待画面と対になった登録側のまま、IP 入力の案内を
「相手のIPアドレス(例: 192.168.1.10)」とはっきり示す形に整えた。
