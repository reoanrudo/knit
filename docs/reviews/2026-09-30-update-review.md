# 自動アップデート機能の独立レビュー(2026-09-30)

実装者とは別の読み取り専用エージェント(code-reviewer)が、更新機能の全体を読んで指摘した。
実機では動かしていない(Mac/Windows/Android の実機での更新適用は未実行)。対応状況は下表のとおり。

## 結論

**最初のレビュー結果は「修正が必要」だった。** 署名検証の中核は堅実だったが、Mac の更新が本番の配布 zip で毎回失敗する欠陥があった(H1)。
通し試験が手作りの zip を使っていたため見逃していた。下記のとおり修正し、通し試験を本番と同じ構成に直した。

## 指摘と対応

| ID | 内容 | 対応 |
|---|---|---|
| H1 | Mac の更新が、本番の配布 zip(版付きフォルダの中に `Knit.app`)の構成で失敗する | **修正**。配布物のフォルダを特定して `release-manifest.json` の版・OS を照合してから `Knit.app` を取り出す。通し試験を `package-mac.sh` と同じ構成に変更し、成功を確認 |
| M1 | Windows でロックが遅く、自動復帰タスクが旧版を起こす隙間がある | **修正**。旧プロセスが終了する前にロックを置く |
| M1 | 入れ替え途中の電源断で実行ファイルが欠ける | **軽減**。実行ファイルを最後に置く。起動時の自動復元は未実装 |
| M1 | Mac の入れ替え中の電源断で `Knit.app` が無くなり得る | **未対応**(発生条件が狭い。既知の制限) |
| M2 | Mac の起動確認が正規表現で、`(` `+` `[` を含むパスで誤って巻き戻す | **修正**。固定文字列で照合。特殊文字を含むパスの試験を追加 |
| M3 | `--update` が起動中の Knit を終了せずに入れ替える | **修正**。起動中なら中止して案内する |
| M4 | 失敗・巻き戻しが利用者に伝わらない(Mac は通知なし、Windows は結果表示が遅い) | **修正**。Mac は入れ替えスクリプトが通知、Windows は起動の前に結果を書く。戻せなかった場合は「戻しました」と表示しない |
| M4 | 対象 OS の成果物が無い時に「最新の版です」と出る | **修正**。「この環境向けの更新はまだ公開されていません」と出す |
| M4 | 署名者が無い版同士の更新で、アクセシビリティ許可が外れることを伝えない | **修正**。更新の通知に再許可の案内を加えた |
| M5 | 署名済みの古い更新情報の再配信(現在版より新しい中間版へ誘導できる) | **未対応(既知の制限)**。通信は https で守られるため実害は小さい。対策は署名対象への有効期限・最低版の追加だが、更新のたびの再署名が要る。署名鍵の運用が決まってから判断する |
| M6 | Android で確認画面が出ないとボタンが押せないまま固まる | **修正**。状態を依頼の前に進め、120 秒で「更新」を再度押せる状態へ戻す |
| M7 | リリース CI で署名鍵がジョブ全体に渡る | **修正**。署名のステップだけに限定し、鍵ファイルは終了時に必ず消す。`--locked` を付けた |
| LOW | `http://127.0.0.1:@evil.com/` のような URL を通す | **修正**。`@` を含む接続先を拒否 |
| LOW | curl に接続タイムアウトが無く、更新情報の取得が最大 15 分待つ | **修正**。接続 15 秒、更新情報 60 秒 |
| LOW | Windows の複製 exe と中断時の作業フォルダが残る | **修正**。起動時に片付ける |
| LOW | 署名にドメイン分離が無い | 未対応(現状は platform で分かれる) |
| LOW | `run_knit.bat` の置換と実行中の cmd の競合 | 未検証・未対応 |
| LOW | `knit-sign` が channel を検証しない | **修正** |
| LOW | シンボリックリンクの扱い | 一部修正(配布物のフォルダと `Knit.app` は実体のみ) |
| LOW | Mac の起動確認は「生きている」だけで、アクセシビリティ未許可でも成功扱い | 未対応(既知の制限) |

## 残る確認

- Mac・Windows・Android の実機での更新の適用(署名鍵の登録後)
- Windows の入れ替えと、自動復帰タスクとの兼ね合い
