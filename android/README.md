# Knit Android 専用アプリ（試作版）

USBデバッグ・ワイヤレスデバッグを使わず、同じネットワークのMacからAndroidを操作するためのアプリです。Android 10以降のarm64端末向け。現在の対象はMacからの操作です。

## 導入

1. 対応するMac版を使い、Knitの「端末を登録…」を開きます。
2. `dist/Knit-Android-preview.apk` をタブレットへ転送し、端末上でインストールします。Android・HyperOSのインストール確認を許可する必要があります。
3. タブレットでKnitを開き、「近くのMacを探す」またはMacのIPv4アドレスを入力し、6桁コードで登録します。
4. 「画面操作の設定を開く」→「設定へ」でKnitのユーザー補助の詳細を開き、使用を有効にします。詳細画面に対応しない端末では一覧を開くので、「ダウンロードしたアプリ」内の「Knit」または「Knit 画面操作」を選びます。キーボードとは別の許可です。サイドロードしたアプリでは、OSが追加の制限付き設定の確認を求める場合があります。端末上で自分で確認してください。
5. 文字入力を使う場合は「Knit キーボード」を有効にして選択します。
6. 「接続を開始」を押します。Macの接続先で、名前の末尾が「Knitアプリ」の端末を選びます。

「登録済み · 未接続」は登録情報を保存しただけの状態です。「接続済み」と表示されてから操作してください。Macで従来のUSB中継を使っている場合も、アプリ対応版への更新が必要です。

6桁コードは初回の安全な登録に使います。既存のMacが旧形式のキーを使っている場合も、対応版ではキーを変更せずAndroidへ登録できます。登録後はKeystoreに保存したキーで暗号化接続するため、接続のたびにコードを入力する必要はありません。既存Windowsのキーや手動インポート方式は変更しません。

以後の接続・操作にUSBデバッグは不要です。ケーブル経由の開発用インストールにADBを使う場合も、実行時の通信はLANのNoise暗号化経路だけを使います。単なるUSBケーブル接続をLAN接続として扱う機能はありません。ネットワークの隔離・ファイアウォールで接続できない場合は、双方が到達できるLANが必要です。

通知の「接続を停止」で停止できます。端末の再起動後・アプリ更新後は、登録済みで停止操作していなければ自動で待機を始めます（停止したまま再起動しても自動開始しません）。再接続の待ち待ちは通知の張り替えを繰り返さない静かなものです。「登録を解除」はこのタブレットの保存キーを削除します。Mac側の共有鍵を変更する操作ではありません。

## 共有で送れるもの

Androidの「共有」からKnitを選ぶと、Macへ送れます。

| 対象 | 対応 |
|---|---|
| 画像（スクリーンショット含む） | 1枚・複数枚どちらも可 |
| 動画 | 可（1ファイル256MiB上限。長い映像は注意） |
| 音声（音声メモ等） | 可（同じく256MiB上限） |
| テキスト | 可 |
| その他ファイル | 可（mime種別を問わない） |

共有はMacがこのタブレットを選択している間に届きます。未接続・未選択で共有した場合は最新1回分だけアプリが保持し、Macとのファイル経路が通った時点で自動送信します（Macの画面の端へカーソルを移動すると選択になります）。Macからタブレットへのファイル送信は、Macの設定画面の「タブレットのDownloadへ送る…」を使います。

## 更新と署名について

配布APKは開発用の署名で作っており、署名はビルド環境ごとに異なります。更新APKで「更新ファイルの署名者が現在と異なるため中止しました」と出たら、APKのアンインストール→再導入が必要です（この場合、Macとの再登録もやり直しになります）。実運用では固定のリリース鍵（`KNIT_ANDROID_KEYSTORE`）へ移行し、署名の一致する更新に切り替える予定です。

## 操作

| 操作 | アプリ版の方式 |
|---|---|
| カーソル | ユーザー補助のオーバーレイ。対象アプリへネイティブのhoverイベントは送りません |
| クリック・ドラッグ | `AccessibilityService.dispatchGesture` によるタッチと継続ストローク |
| 右クリック | 長押し |
| スクロール・ピンチ | 1本指のスワイプ・2本指のタッチ |
| 戻る・ホーム・最近のタスク・スクリーンショット | Androidの公開グローバルアクション。保護された画面などではOSに拒否されます |
| 前／次のアプリ | サービスが観測した直近のアプリ履歴から起動。HyperOSのタスク順序を直接読み取る方式ではありません。履歴がない場合は最近のタスクを開きます |
| 英数字入力・編集・コピー／貼り付け | Knit IMEのInputConnection。直接入力の配列表はUS基準 |
| 日本語・全角英数 | Knit IME内のオフラインMozc。入力欄に未確定文字を表示し、Spaceで変換、Enterで確定。候補はタブレットの画面下で選択。「かな」／「英数」と「あ／A／Ａ」で切替。F9でも全角英数へ変換できます |
| 絵文字・確定済みテキスト | クリップボードの貼り付け、またはMacの「タブレットへ文字を入力…」から送信 |
| テキストコピー | Knitキーボード選択中、またはKnit画面を開いている時に同期。許可がない背景状態では次回の適用を待ちます |
| ファイル | 暗号化した別TCP経路。受信後はDownloads/Knitへ保存。送信はAndroidの共有からKnitを選択。画像・動画・音声メモ・テキスト・ファイルに対応し、複数選択でも送れます（1ファイル256MiB上限。動画は長い映像で上限を超えやすいので注意） |
| 画像コピー | Macから受信した非圧縮24/32bit DIBをPNGとしてPictures/Knitへ保存し、利用可能な状態でクリップボードへ適用 |
| URL | 受信したhttp/https URLをKnit画面から明示的に開く |

液晶の寸法はAndroidの物理DPIから送信し、Macの配置図へ反映します。取得できない場合は従来の概算表示です。画面回転時は解像度を更新します。

## 安定性・保護

- 通信は既存の`knit-common`のNoiseとSPAKE2をRustから使用します。Javaから平文TCPを作りません。
- 登録キーと接続先はAndroid KeystoreのAES-GCMで暗号化して保存。保存完了後にだけ登録成功を返します。バックアップ・端末転送から除外します。
- 画面の文字を読み取る機能や、入力・音声を記録して分析する機能は追加していません。ユーザー補助の画面内容取得は無効です。アプリ切替用のパッケージ履歴はプロセスのメモリー内だけです。
- 停止・離脱・接続終了時にタッチを終了し、カーソルを隠します。ロック中は操作を受け付けません。
- 接続世代を確認して古い受信・送信を適用しません。大容量経路はMacで選択中の接続先へ制限します。
- 日本語変換は端末内で完結します。変換用の外部通信、入力のログ記録、変換履歴の学習は行いません。入力欄の切替・離脱・切断では変換状態を終了します。

Android 0.1.1以降と対応Mac版では、通常の日本語入力にMac側の入力バーは不要です。辞書の準備が完了したことをAndroidから暗号化経路で通知し、Macは直接キーを転送します。旧Androidアプリへの接続ではMac側の入力方式を維持します。

## ビルドと検証

JDK17、Android SDK36、NDK28.2.13676358、Rustを用意します。MacまたはLinuxから実行します。

```sh
ANDROID_HOME=/path/to/android-sdk ANDROID_NDK_HOME=/path/to/ndk JAVA_HOME=/path/to/jdk17 scripts/build-android.sh lintDebug
```

Gradle8.14.3は同梱Wrapperが取得します。出力は`dist/Knit-Android-preview.apk`。初回は固定版のMozcソースとBazel依存関係を取得し、ネイティブライブラリと辞書を生成するため数分かかります。生成物・ソースキャッシュはGitの対象外です。[Mozcのビルドとライセンス](third-party/Mozc.md)を参照してください。`scripts/build-android.sh assembleDebugAndroidTest`で一時エミュレーター専用の実行テストAPKも作れます。

- Rustアダプター: 暗号化Unicode往復、切断による待機解除、巨大行の拒否、別暗号化経路でのファイル往復。
- Android単体: キー入力と編集キーの分離・記号の扱い。
- Android16の一時エミュレーター: 6桁登録とKeystore、JNIの日本語・絵文字、接続、実際のタップ／ドラッグ／ピンチ、IMEの日本語入力とキー、MediaStoreファイル保存、停止を実行検証します。

`crates/android-bridge/examples/fixture.rs`と`SmokeTest`は個人端末では実行しません。テスト用の固定鍵をアプリの既定値にすることはありません。

## 残る制約

本アプリは試作版です。画面ミラーリング・タブレットの音をMacで鳴らす音声転送・Gboard等への直接キー注入は未実装です（音声メモや動画などのファイルは、共有からKnitを選べば送れます）。日本語変換にはMozcの公開辞書を使用します。Google日本語入力の非公開辞書・クラウド候補と同じ候補になる保証はありません。Knit独自のフリック式ソフトウェアキーボードは提供しません。ファイルの受信保存は対応しますが、別アプリへのファイルの掴みドラッグは提供しません。Android側の制約で保護画面や一部アプリの入力には対応できない場合があります。

アプリ版とADB中継を同時に有効にすると、別の端末IDとして表示されます。USBデバッグを無効にした状態でアプリ版を使う運用を推奨します。日本語の直接入力にはKnit IMEの選択が必要です。

HyperOSの実機でデバッグを無効にした連続操作、回転、再接続、長いドラッグ、他社IMEからの戻しは、ユーザーがインストールと権限を許可した後に確認する必要があります。エミュレーターの結果を実機保証とは扱いません。

API根拠: [AccessibilityService](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService)、[InputMethodService](https://developer.android.com/reference/android/inputmethodservice/InputMethodService)、[Android Keystore](https://developer.android.com/privacy-and-security/keystore)。
