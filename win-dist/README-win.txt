Knit for Windows ─ 導入手順
================================

Knit(つなぐ)は、MacBook のキーボード/トラックパッドでこの PC を操作できるように
するツールです。カーソルを画面の端へ動かすだけで Mac ⇄ Windows が切り替わり、
クリップボード(テキスト/画像/ファイル)と音声も共有されます。

トレイアイコンを右クリックすると「クリップボード履歴」があり、画面を越えて送受信した
テキストから選んでこの PC に貼り付けられます(最大 50 件。トレイアイコンには接続状態と
遅延・履歴件数を表示します)。

インストール
------------
1. このフォルダを任意の場所(例: C:\Users\<ユーザー>\knit)へ置く
2. install.bat を右クリックして「管理者として実行」
   (スタートアップ登録・自動復帰登録・起動まで行います。以降の起動に
   管理者権限は不要です)
   ※ 「WindowsによってPCが保護されました」と表示されたら「詳細情報」→
   「実行」を選んでください(開発者署名のないアプリの標準手順です)
3. タスクトレイに Knit のアイコンが出れば完了です

旧 Tsunagu から乗り換える方
----------------------------
install.bat が旧版(Tsunagu)の自動起動と常駐を止めて、設定(.env)も引き継ぎます。
設定とクリップボード履歴は初回起動時に自動で引き継がれ(旧データも残ります)、
やり直しになるのは「端末の登録」だけです。
もう1台の Mac も必ず Knit へ更新してください。片側だけだと接続できません
(Mac 用は GitHub Releases の Knit-<版>.zip から入手できます)。

はじめての接続
------------------
1. Mac 側で Knit を起動します(初回は登録の画面が自動で出ます。2回目以降は
   メニューバーの Knit →「設定…」→「接続」の「端末を登録…」から開けます)
2. この PC で Knit を起動すると、同じネットワークの Mac を自動で見つけます
   (Mac が1台なら自動で確認が始まります)
3. Mac の画面に出た4桁の確認番号と同じものを、Windows の4つの候補から選び、
   Mac 側で「許可」を押します。登録はこれで完了です
4. 自動で見つからないときは、Mac の画面に表示される6桁の手入力コードを
   Windows 側に入力するか、Mac の IP アドレスを指定できます

コードは5分間有効、最大3接続試行、登録成功1回で終了します。
入力を間違えた場合は画面内で修正できます。期限切れならMacで新しいコードを作成してください。
長い暗号化キーはアプリが内部で交換・保存します。手動で渡す必要はありません。

新規キーはWindowsのユーザー単位で保護して保存します。
既存の.env設定がある場合はそちらを優先し、変更しません。
公開用Zipにはキー・設定を同梱しません。

使い方(概要)
--------------
- Mac のカーソルを画面右端へ(既定は 2 回)→ Windows へ切替
- Windows のカーソルを画面左端へ → Mac へ戻る
- Mac でコピーしたテキスト/画像/ファイルは、切替後に Ctrl+V で貼り付け可
  (ファイルは Downloads\Knit に保存されます)
- Windows の音は接続中 Mac 側だけで鳴ります(設定で変更可)

ステータスウィンドウ(タスクトレイを左クリック)
------------------------------------------------
- 状態/遅延(色付き)/音声/スピーカー/ファイル受信/Mac の設定を常時表示
- 「Mac へ戻る」: そのまま Mac に制御を戻します(境界まで動かさなくても可)
- 「受信フォルダ」: 受信したファイルのフォルダを開きます
- 「サーバー(Mac)」欄: Mac のアドレスを編集して「保存して再接続」で切替
- 音声 ON/OFF・ログ・再起動・終了もここから

うまくいかないときは
--------------------
旧フォルダ(%USERPROFILE%\tsunagu)は残してあるので、その中の install.bat を
もう一度実行すれば、旧版(Tsunagu)へ戻れます。

アンインストール
----------------
uninstall.bat をダブルクリックしてください(常駐停止・登録解除・ファイル削除)。
