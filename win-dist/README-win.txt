Tsunagu for Windows ─ 導入手順
================================

Tsunagu(つなぐ)は、MacBook のキーボード/トラックパッドでこの PC を操作できるように
するツールです。カーソルを画面の端へ動かすだけで Mac ⇄ Windows が切り替わり、
クリップボード(テキスト/画像/ファイル)と音声も共有されます。

インストール
------------
1. このフォルダを任意の場所(例: C:\Users\<ユーザー>\tsunagu)へ置く
2. install.bat をダブルクリック(スタートアップ登録・自動復帰登録・起動まで行います)
3. タスクトレイに Tsunagu のアイコンが出れば完了です

共有トークン(.env)
------------------
Mac 側と同じトークンを .env ファイル(TSUNAGU_TOKEN=...)としてこのフォルダに置く
必要があります。Zip に同梱済みなら設定は不要です。無い場合は Mac 側の
~/.config/tsunagu/env の内容を .env としてコピーしてください。

使い方(概要)
--------------
- Mac のカーソルを画面右端へ(既定は 2 回)→ Windows へ切替
- Windows のカーソルを画面左端へ → Mac へ戻る
- Mac でコピーしたテキスト/画像/ファイルは、切替後に Ctrl+V で貼り付け可
  (ファイルは Downloads\Tsunagu に保存されます)
- Windows の音は接続中 Mac 側だけで鳴ります(設定で変更可)

アンインストール
----------------
uninstall.bat をダブルクリックしてください(常駐停止・登録解除・ファイル削除)。
